# Tilo 快速上手指南 (Quick Start)

> English version → [../en/QUICK_START.md](../en/QUICK_START.md)

本指南旨在帮助你在 **5–10 分钟内** 掌握 Tilo 的核心工作流，并完成你的第一个“计划与实际执行（Plan vs Actual）”完整闭环。

---

## 1. Tilo 是什么

Tilo 是一个围绕 **“捕获 → 规划 → 执行 → 记录 → 复盘”** 构建的个人执行与时间管理系统：

```text
Capture (捕获) → Plan (规划) → Execute (执行) → Actual (实绩) → Review (复盘)
```

与传统的 To-Do 清单不同，Tilo 不仅记录“你要做什么”，更重要的是同时记录：
- **我原本计划什么时候做**（Planned Block）
- **我实际上什么时候投入了专注**（Actual Session）
- **计划与现实之间的客观偏差**（Plan vs Actual Variance）

---

## 2. 第一次完整使用流程

我们通过一个真实的案例来走通整个生命周期：
- **长期目标 (Goal)**：完成硕士学位论文 (`Complete Master Thesis`)
- **阶段项目 (Project)**：PPP 算法实验研究 (`PPP Algorithm Research`)
- **具体任务 (Task)**：运行 Run47 组对比分析 (`Run47 Analysis`)
- **预估耗时 (Estimate)**：90 分钟 (`90 min`)

```text
创建 Goal
   ↓
创建 Project (关联 Goal)
   ↓
创建 Task (设置 90m 预估)
   ↓
安排至 Today
   ↓
设为 Focus #1 核心焦点
   ↓
拖入 Timeline 创建 Planned Block
   ↓
点击 Start Session 启动专注计时
   ↓
中途 Pause / Resume
   ↓
完成任务 Finish Session
   ↓
查看 Plan vs Actual 幽灵/实色对比
   ↓
执行 Daily Close 每日收尾
```

### 第一步：创建目标与项目 (Goal & Project)
1. 点击左侧导航栏的 **目标 (Goals)**，点击右上角 **新建目标**，输入 `Complete Master Thesis`，颜色选择 Indigo。
2. 进入 **项目 (Projects)** 页面，点击 **新建项目**，输入 `PPP Algorithm Research`，主目标 (Primary Goal) 选择刚才创建的 `Complete Master Thesis`。

### 第二步：创建任务并设定预估时间 (Task & Estimate)
1. 在项目内或通过快捷键 `Ctrl+K`（macOS 为 `Cmd+K`）呼出命令菜单，输入 `Run47 Analysis` 创建任务。
2. 点击任务打开右侧 **检视器 (Inspector)**：
   - 预估耗时 (Estimate)：填入 `90` 分钟。
   - 安排日期 (Scheduled Date)：设为今天 (`Today`)。

### 第三步：在 Today 视图设定焦点并排期 (Focus & Timeline)
1. 点击侧边栏进入 **今日 (Today)** 页面。
2. 在左侧未安排任务中，点击 `Run47 Analysis` 右侧的聚焦图标，将其设为 **今日聚焦 #1 (Focus #1)**。
3. 将该任务直接从待安排列表**拖拽 (Drag & Drop)** 到右侧的 **时间轴 (Timeline)** 14:00 位置，系统会自动生成一个 14:00–15:30 的 **计划时间块 (Planned Block)**。

### 第四步：启动执行与计时 (Session Execution)
1. 在时间轴计划块或左侧聚焦卡片上，点击 **开始 (Start Session)**。
2. 界面右下角将弹出 **浮动计时器 (Floating Timer)**，进入前台有效专注状态。
3. 如遇临时打断，点击 **暂停 (Pause)**（暂停期间不计入核心有效专注时长）；处理完毕后点击 **继续 (Resume)**。
4. 任务执行完毕后，点击 **完成 (Finish)** 结算会话并自动将任务状态流转为已完成 (`Done`)。

### 第五步：查看 Plan vs Actual 对比
1. 观察今日时间轴：
   - **半透明虚线框 (Ghost Block)**：代表原本计划的 14:00–15:30（90分钟）。
   - **实色块 (Solid Block)**：代表实际执行时间段（例如 14:15–15:45）。
2. 点击时间块，在右侧 **检视器 (Block Inspector)** 中查看客观偏差：“晚开始 15 分钟，实际专注时长 82 分钟（已排除暂停 8 分钟）”。

---

## 3. 第一天结束：每日收尾 (Daily Close)

在一天工作结束时（通常用时 1–2 分钟）：
1. 在 Today 页面点击右上角 **每日收尾 (Daily Close)**，或通过侧边栏进入 **复盘 (Review)** 页面。
2. **解决遗留 (Resolve)**：查看未完成任务，客观选择“延后至明天”、“移入收件箱”或“标记取消”。
3. **记录反思 (Reflect)**：选填今日反思与备忘。
4. **确认封存 (Close)**：点击确认封存，系统将为今日生成不可篡改的历史执行快照。

---

## 4. 第一周结束：每周复盘 (Weekly Review)

周末或下周一早晨，进入 **复盘 (Review)** 页面开启 **每周复盘向导 (Weekly Review)**：
- **01 概览 (Overview)**：查看本周计划与实际执行总时间、任务完成率。
- **02 计划与实绩 (Plan vs Actual)**：审视时间准确度与时间轴偏差。
- **03 目标推进 (Goals)**：查看主目标与关联项目的进度沉淀。
- **04 执行模式 (Patterns)**：分析临时插入工作 (Unplanned Work) 与改期原因。
- **05 周度反思 (Reflection)**：编辑自动生成的周度客观叙事并记录总结。
- **06 下周展望 (Next Week)**：选定下周战略聚焦目标，完成周快照归档。
