# Tilo 数据存储与备份指南 (Data & Backup)

> English version → [../en/DATA_AND_BACKUP.md](../en/DATA_AND_BACKUP.md)

---

## 1. 本地优先存储架构 (Local-first)

Tilo 是一款严格遵循**本地优先 (Local-first)** 原则构建的工具：
- **存储位置**：你的所有目标、项目、任务、时间块、专注记录、复盘快照及自定义配置，全部存储在当前浏览器本地的 **IndexedDB (基于 Dexie.js 引擎)** 中。
- **无云端依赖**：Tilo V1 **不包含任何云端数据库、远程服务器或第三方同步服务**，数据完全属于你的设备，享有 100% 的隐私保障。

---

## 2. 浏览器数据清理风险 (Browser Data Risk)

> [!WARNING]
> **重要安全提示**：
> 由于数据驻留在浏览器本地，如果你在浏览器设置中执行了 **“清除浏览数据 / 清理站点 Cookie 及缓存 / 重置浏览器”**，本地存储的 IndexedDB 数据将被浏览器直接删除。

### 保护你的数据：
1. **避免在无痕/隐私模式 (Incognito) 下长期使用**：部分浏览器关闭无痕窗口时会自动销毁所有 IndexedDB 数据。
2. **定期导出 JSON 备份文件**：建议每周或每月导出一次备份文件并妥善保存在本地硬盘或私有云盘中。

---

## 3. 导出全量备份 (Export Backup)

1. 点击侧边栏底部的 **设置 (Settings)**，进入 **数据 (Data)** 标签页。
2. 点击 **导出 JSON 备份 (Export Backup JSON)** 按钮。
3. 浏览器将自动下载一个形如 `tilo-backup-YYYY-MM-DD.json` 的标准 JSON 文件。
4. 导出的备份包含当前工作区的全量 23 张数据表结构及全部历史记录。

---

## 4. 恢复备份与数据校验 (Restore & Validation)

1. 在 **设置 → 数据** 页面中，点击 **选择备份文件导入**，或将 `.json` 备份文件直接拖入上传区域。
2. **结构前置校验 (Pre-write Validation)**：
   - Tilo 会使用 Zod Schema 对导入的 JSON 文件进行严格的数据完整性校验。
   - 若备份文件损坏或非 Tilo 格式，系统将拒绝写入并抛出明确的错误提示，保护现有数据库免受污染。
3. 校验通过后，系统将在事务（Transaction）中完成数据写入并自动刷新工作区。

---

## 5. 重置与演示数据 (Reset & Demo Data)

- **重置为演示工作区 (Seed Demo Data)**：如果你想快速体验丰富的数据分析与日历排期，可在数据设置中点击“重置并加载演示数据”。
- **清空工作区**：在导入全新备份前，可根据需要重新初始化工作区。

---

## 6. 常见数据问题解答

- **Q: 可以在不同电脑之间同步吗？**  
  A: Tilo V1 暂无自动云同步功能。你可以通过在电脑 A 导出 JSON 备份，并在电脑 B 导入该 JSON 文件来实现数据迁移。
- **Q: 换浏览器后数据还在吗？**  
  A: 不同浏览器（如 Chrome 与 Edge、Safari）的本地 IndexedDB 存储空间是相互隔离的。若更换浏览器，需导出并导入 JSON 备份。
