# Tilo — Branding Contract

## Final name

The product name is **Tilo**. Earlier working titles are retired and must not appear in implemented UI, package metadata, backup filenames, tests, fixtures, screenshots, or documentation created after bootstrap.

## V1 visual identity

- Product name: `Tilo`
- Style: restrained, modern, Linear-like productivity UI
- Primary accent: Indigo
- Default theme: Light; Dark/System supported
- Brand mark: seamless monolithic Indigo 'T' mark with organic fillets (`src/components/ui/TiloLogo.tsx` and `public/favicon.svg`).
- Typography direction: Geist/Inter-like modern sans serif
- Copy tone: factual, calm, non-motivational

## Naming conventions

- Browser/document title: `Tilo`
- Backup filename: `tilo-backup-YYYY-MM-DD.json`
- Suggested package name: `tilo` (or a valid scoped alternative if the package registry requires one)
- Default workspace label remains `Personal workspace` unless the user changes it.

## Design references

Screenshots in `docs/design/reference/` define layout and visual direction, while `docs/MASTER_PLAN.md` defines behavior. If a screenshot conflicts with the written specification, the written specification wins.
